# Social Dual Post

将对话、文字和图片素材梳理成独立主题，等待用户选择主题与平台，再生成适配的文章或图文内容。

当前版本：**0.4.3**。保持文件型 Skill 的最小范围，不包含个人偏好学习、自动评测系统或自动发布。

## 使用

将整个目录安装到 `~/.codex/skills/social-dual-post/`。固定安装本次版本（目标目录需不存在）：

```bash
git clone --branch v0.4.3 https://github.com/futurecodersh/social-dual-post.git ~/.codex/skills/social-dual-post
```

下一轮调用：

```text
用 $social-dual-post 梳理本次对话，列出独立主题和可写角度，
先不要写文章。
```

- “根据这组图片给两个写作方向，先不写稿。”
- “就第2个主题写朋友圈，长一点。”
- “第1和第3个主题分别写抖音图文，不要合成一篇。”
- “你从这些主题里选一个，写朋友圈。”（明确委托后可以代选）
- “给这个抖音稿生成配图。”（需要运行环境有图像工具）
- “把这份稿件保存到指定目录。”

默认先在聊天中交付主题清单，不自动选一题或默认出两个平台的稿件。主题和平台已明确时可直接写，不重复确认。只使用当前可见或明确提供的素材；不会自动读取其他聊天、历史文章或偏好文件。没有图像工具时可交付画面建议和提示词，不能假称已出图。

## 内容

```text
SKILL.md                  三步流程、平台输出、事实边界
references/few-shot.md    文字与图片素材的合成写作示例
CHANGELOG.md              版本记录
```

示例用于学习结构和表达，不是用户的真实经历，不要照抄。模型的实际写作质量仍需用户检验。

## 更新说明

0.4.0 删除旧版偏好读取、反馈记录和分维评分流程，不新增或维护个人数据。已有用户记录保留在原处，不读取、迁移或删除。源仓库用 Git 管理，安装目录是使用副本；此版本没有升级数据格式，也没有迁移脚本。
