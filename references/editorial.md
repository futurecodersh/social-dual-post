# 编辑标准与参考方法

这些是编辑取向，不是平台算法研究，不代表某种文风能保证增长。

## 怎样判断“高级、有深度”

- 观察具体：指出真实问题，少从“快速变化的时代”起笔。
- 判断有增量：解释容易混淆的区别、被忽略的条件或有代价的选择，不只给常识换词。
- 论证跟得上：让读者看见观察如何支持判断，一个例子不推出所有人都如此。
- 语言有控制：准确动词、清晰主语、长短句变化。比喻照亮机制，不能代替机制；允许文学感，删除无依据的拔高。
- 结尾有余味：落在正文推出来的认识上，不突然转向时代、人生与命运。

普通读者第一次能懂，愿意停留的人能找到值得回想的区分。深刻不等于晦涩，清楚不等于幼稚。

## 可迁移的创作者方法

学习方法，不仿写声音。链接在用户询问参考依据时提供；普通写稿无需每次重新浏览。涉及作者具体观点或引语时核对原文。

- Paul Graham，《How to Write Usefully》：结合信息的真实性、重要性与新意。编辑动作：逐段检查读者增加了什么认识。https://www.paulgraham.com/useful.html
- Paul Graham，《Write Simply》：用常见词和清晰句子。编辑动作：朗读并删除需要反复解码却不增加信息的句子。https://www.paulgraham.com/simply.html
- swyx，《Learn in Public》：分享学习中解决的问题，面向曾经困惑的自己。编辑动作：保留真实进展，不假装已是专家。https://swyx.io/learn-in-public

这些是通用写作方法来源；朋友圈与抖音的篇幅、卡片结构是本 Skill 的可调整选择，不声称获得作者或平台验证。

## 可选参考：广告文案的聚焦与记忆点

用户提出金枪大叔作为可能的参考。公开出版页面显示其本名岳华平，身份为广告策划人、导演，著有《借势》；其公开材料与广告、营销和个人传播相关，不能仅据此认定他是朋友圈长文写作的最佳范本。

核实来源：[《借势》出版页面（磨铁数盟提供，豆瓣阅读）](https://read.douban.com/ebook/402630852/)。[广告门专访页面](https://www.adquan.com/article/319412) 可确认广告领域背景，但全文有会员限制；本 Skill 未读完整专访或全书，不把社区整理的“金枪大叔 Skill”当作作者官方方法论。

对当前用途的编辑建议（以下为本 Skill 的选择，不冒充作者原话或经验证的个人风格模型）：

- 聚焦一个值得读的问题，让开头迅速呈现真实张力；避免强行反常识。
- 用一个具体画面或例子承载判断，再回到主要矛盾，不堆史料与术语。
- 将值得记住的表达放在论证自然成立的位置，不定“每篇三句金句”配额。
- 朋友圈保留熟人交流的可信语气，慎用叫卖、绝对化断言、制造焦虑和刻意争议；抖音封面可更集中，但正文必须兑现。

默认不切换成某位博主的口吻，不声称“照着他写就适合朋友圈”。用户指定具体作品时再读可访问的原文，提取结构、节奏、例子使用等可描述特点；无法取得全文则说明材料不足，继续按用户目标写，不伪称分析过。文章可以选择问题—解释—回扣或总—分—总，不是所有题目都强制同一结构。

## 编辑示例

虚构示例素材：用户说“我准备整理书签，先看看哪些还能解决眼前的问题；目前还没开始”。

空泛写法：“每一次知识整理，都是个人资产的复利。”

可展开的判断：“整理可以从一个正在遇到的问题开始。”随后解释：按眼前用途筛选资料，有助于区分现在能用的材料和暂时用不上的材料。这是编辑分析，不是用户已经验证的效果。

朋友圈从准备整理书签的动作切入，让论述自然出现；抖音可分解为“整理的起点 → 怎么筛选 → 如何尝试”，每页增加信息。保留准备尝试的阶段，不虚构坚持天数、提升比例和效果。
